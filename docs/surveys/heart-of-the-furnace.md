## 3. Custom Preset 調査

| 設定 | 対象 | 時計 | 杯 | 冠 |
| --- | --- | --- | --- | --- |
| setting1: 星反応火力型 | オデット、旅人(氷)、八重神子、ミティヤ | 攻撃% / 熟知 | 攻撃% / 熟知 | 会心率 / 会心ダメージ / 熟知 |
| setting2: 攻撃参照の回復支援型 | アリョーシャ、七七 | ER% / 攻撃% | 攻撃% | 治療 / 攻撃% / 会心率 |

花は HP、羽は攻撃力の固定メイン。設定1・2は役割と必要ステータスを分けた。

### Setting1 の設計

- 候補は `CR / CD / ATK% / EM / ER`。花・羽は3個以上かつ会心率・会心ダメージを両方必須。時計・杯・冠は2個以上、黄色☆なし。
- Inference: 時計・杯の熟知許可は旅人 / 八重の代替候補を拾うための和集合。オデットは攻撃時計・攻撃杯を基本とする。
- Inference: ER は爆発を使う運用向けの補助候補。ミティヤ追加時に熟知メイン＋片会心＋ERを拾えるよう追加したが、共通の必須にはしない。
- 八重は熟知時計＋熟知杯を同時採用しない。部位をまたぐ条件はこの YAML では表せない。

### Setting2 の設計

- 候補は `ER / CR / ATK% / ATK` の2個以上。必須指定はなし。
- Inference: 回復に有効な攻撃実数も残す。羽には攻撃実数サブが付かないため、ER / 会心率 / 攻撃% のうち2個が必要になる。
- Inference: 西風の会心率と ER は武器・凸・回し方次第。共通の必須条件にせず、ER メイン時計や会心率メイン冠も成立させる。
- 七七の ER 時計は爆発を使う運用向けの追加許可。通常の攻撃時計を置き換える推奨ではない。
- 七七の炉炎採用は JP の候補と発動条件に基づく代替案。千岩等を使い、オデットに炉炎を任せる編成も多い。
- アリョーシャは星反応の有効化役ではない。氷下地と、自身による反応発動を確保する。

### 黄色☆の再調査と決定（2026-10-18）

優先順位の再確認: [KQM オデット](https://keqingmains.com/q/odette-quickguide/) と
[BWiki オデット攻略](https://wiki.biligame.com/ys/奥黛塔/攻略) は会心を重視。
[BWiki アリョーシャ攻略](https://wiki.biligame.com/ys/阿罗夏/攻略) は必要量までのチャージと、西風使用時の会心率を重視する。
[KQM アリョーシャ](https://keqingmains.com/q/alyosha-quickguide/) では C2 以上で2ローテーションに1回の爆発なら ER 投資がほぼ不要となる場合もある。
[KQM 七七](https://keqingmains.com/q/qiqi-quickguide/) も会心率は西風用、回復は攻撃参照とする。

| 設定 / 部位 | 候補 | 必要個数 | 必須（黄色☆） |
| --- | --- | --- | --- |
| 設定1 / 花・羽 | 会心率・会心ダメージ・攻撃%・熟知・チャージ | 3 | 会心率・会心ダメージ |
| 設定1 / 時計・杯・冠 | 会心率・会心ダメージ・攻撃%・熟知・チャージ | 2 | なし |
| 設定2 / 全部位 | チャージ・会心率・攻撃%・攻撃実数 | 2 | なし |

- Inference: 設定1の花・羽は固定メインで集めやすいため、両会心＋攻撃% / 熟知 / ERのいずれかを保持基準とする。攻略が指定したロック条件ではなく、在庫整理のための選別。
- 時計・杯は特定の片会心を黄色☆に固定しない。2026-11-17のER追加後は、熟知＋ERなど会心なしの組み合わせも通るため、これは保持候補を広く拾う条件となる。
- 冠は会心率 / 会心ダメージ / 熟知を許可するため、共通の会心必須を置かない。熟知サブの必須化も熟知冠と両立しないため行わない。
- 設定2は ER メイン時計、会心率メイン冠、非西風武器、爆発頻度の違いを共通設定で扱う。ER / 会心率 / 攻撃% のどれも全部位共通の必須にはしない。
- 両会心必須では、片会心が大きく伸びた花・羽や会心率が過剰な装備向けの品も外れる。強化済み品は伸びと最終装備の会心率を個別確認する。

## 4. 適用と限界

- 設定1・2は保持候補を追加する用途。両方の型を残す場合は両方を有効化する。
- 推奨が使える場合は既存方針どおりゲーム内推奨も有効化するが、その内容は今回は未転記。
- `main_allowed` は主ステを照合するヒント。UI で必須にできると仮定しない。
- 主ステと同名のサブステは付かない。必須指定は花・羽に限り、各メインでも閾値を満たせるよう検証する。
- Inference: 個数の閾値は在庫整理用の独自判断で、各ガイドの指定値ではない。
- 未ロックは自動的な処分判定ではない。強化済み品、他セットの自由枠、HP / 熟知支援型は別途確認する。
