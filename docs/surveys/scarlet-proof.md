## 3. Custom Preset 調査

| 設定 | 対象 | 時計 | 杯 | 冠 |
| --- | --- | --- | --- | --- |
| setting1: 攻撃参照の星拡散キャリー | ヴェスナ | 攻撃% / 熟知 | 攻撃% / 熟知 | 会心率 / 会心ダメージ |
| setting2: 熟知参照の星拡散ドライバー | 夢見月瑞希 | 熟知 | 熟知 | 会心率 / 会心ダメージ / 熟知 |

花は HP、羽は攻撃力の固定メイン。厳しさ違いではなく、ダメージ参照ステータスの違いで分けた。

### Setting1 の設計

- 花・羽は `CR / CD / ATK% / EM / ER` の3個以上かつ会心率・会心ダメージを両方必須。
- 時計・杯は `CR / CD / ATK% / EM` の2個以上、冠は `CR / CD / ATK% / EM / ER` の2個以上。黄色☆なし。
- Inference: 時計・杯では ER を候補から外し、攻撃% / 熟知メインで熟知＋ERだけの無会心品が通らないようにする。必要な ER は花・羽・冠や武器も含めて確保する。
- ヴェスナは攻撃時計＋攻撃杯が基本。熟知メインを使う場合は最大1部位、熟知バフがない編成向け。
- 時計と杯の同時条件は YAML では表せない。両部位の熟知許可は、熟知＋熟知を推奨する意味ではない。
- 星拡散を伸ばすため、風元素ダメージ杯を共通候補に含めない。

### Setting2 の設計

- 花・羽: `CR / CD / EM` の2個以上かつ会心率・会心ダメージを両方必須。
- 時計・杯: メイン熟知、`CR / CD` の1個以上。
- 冠: `CR / CD / EM` の1個以上。会心メインなら熟知または反対側の会心、熟知メインなら会心を拾う。
- 時計・杯・冠は必須指定なし。攻撃%・ER を候補に含めない。
- 入力時は花・羽の会心率と会心ダメージだけ黄色☆。時計・杯は片会心のどちらでもよく、特定の片方を必須にしない。
- Inference: 熟知メインの希少部位は片会心でも残す。両会心必須にすると強化途中の候補を落とすため、花・羽と部位別に閾値を変えた。
- 熟知冠は主に C6 または手持ち比較向け。通常は会心冠を優先する。
- 通常拡散用の熟知だけのビルドと混同しない。星拡散の有効化条件を満たした編成で使う。
- 金メッキ4・熟知2+2も有力。炉炎と同じ秘境で得た紅血の在庫活用が目的で、紅血が常に最適とはしない。

### 黄色☆の再調査と決定（2026-10-18）

[KQM 瑞希](https://keqingmains.com/q/mizuki-quickguide/) は会心を熟知と同等以上に評価し、ER を積極的に伸ばさない。
[BWiki ヴェスナ攻略](https://wiki.biligame.com/ys/薇斯纳/攻略) も会心を重視し、ER は武器・編成・爆発頻度次第とする。
KQM ヴェスナの Ver.7.1 インフォグラフィックとも照合した。

| 設定 / 部位 | 候補 | 必要個数 | 必須（黄色☆） |
| --- | --- | --- | --- |
| 設定1 / 花・羽 | 会心率・会心ダメージ・攻撃%・熟知・チャージ | 3 | 会心率・会心ダメージ |
| 設定1 / 時計・杯 | 会心率・会心ダメージ・攻撃%・熟知 | 2 | なし |
| 設定1 / 冠 | 会心率・会心ダメージ・攻撃%・熟知・チャージ | 2 | なし |
| 設定2 / 花・羽 | 会心率・会心ダメージ・熟知 | 2 | 会心率・会心ダメージ |
| 設定2 / 時計・杯 | 会心率・会心ダメージ | 1 | なし |
| 設定2 / 冠 | 会心率・会心ダメージ・熟知 | 1 | なし |

- Inference: 固定メインの花・羽は両会心品に絞る。瑞希は時計・杯で熟知を確保するため、花・羽の熟知サブまでは必須にしない。
- 時計・杯は希少なメイン候補と片会心品を残す。会心率だけを黄色☆にすると、紅血の会心率バフや武器との組み合わせで使える会心ダメージ品を失う。
- 冠に共通の会心必須は置かない。会心メインと同名のサブは付かず、瑞希は熟知冠も選べるため。
- 攻撃% / 熟知 / ER はメイン・武器・味方のバフでも確保できる。全部位のサブに存在することは要求しない。
- この両会心必須は攻略の指定ではなく在庫選別の推論。片会心が大きく伸びた花・羽は外れるため、強化済み品は個別確認する。

## 4. 適用と限界

2026-10-18 追記: ユーザー提供の独自設定操作画像では、設定2の杯で会心率だけが黄色☆になっていた。
これは `substats_required_all_of: [CR]` に相当するが、今回の authored rule は意図的に `[]` としている。
画像は UI 操作の説明根拠として `docs/ui-mapping.md` に記録し、YAML を会心率必須へ変更する根拠にはしない。

- 型を両方残す場合は設定1・2を両方有効化。推奨の内容は証跡到着後に別途転記する。
- `main_allowed` は主ステの照合用ヒント。UI で必須指定できると仮定しない。
- 会心メインに同じ会心サブは付かない。全部位で両会心必須にはしない。
- セット由来の会心率+16%や編成の会心率バフを含め、最終装備で過剰にならないよう調整する。
- Inference: サブステ個数の閾値は保持候補を選ぶ独自判断。ガイドがロック条件を指定しているわけではない。
- サブステの伸び回数・数値はこの形式では判定できない。未ロックを自動処分リストにはしない。
